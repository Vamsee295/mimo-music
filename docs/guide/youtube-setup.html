Step by step
01 / Get the key

Six steps to full songs

01

Create a Google Cloud project

Sign in with Google, name it Mimo, press Create. Accept the terms if asked. It's free.

Openconsole.cloud.google.com/projectcreate
02

Turn on YouTube Data API v3

With your Mimo project selected at the top, press Enable.

Openconsole.cloud.google.com/apis/library/youtube.googleapis.com
03

Create an API key

Open Credentials, then:

Create credentials→API key
Openconsole.cloud.google.com/apis/credentials

tipA key starts with AIza and is exactly 39 characters. Not the "OAuth client ID".

04

Lock the key to YouTube (recommended)

On the key press Edit API key → Restrict key → tick only YouTube Data API v3 → Save. Leave "Application restrictions" on None so the Android app can use it.

05

Paste it into Mimo

On the API keys row press Show key, copy it. In Mimo:

You→Settings→Full songs (YouTube)

Paste it into YouTube Data API key.

06

Test, then save

Press Test. When it says Working, press Save settings.

Key added: songs play in full

02 / How it runs

Your key, your quota

The daily quota

Google gives every key 10,000 units a day. Finding a song's video costs 100, so that's about 99 new songs a day.

1 new song = 10010,000 / day

Songs you've played before are remembered on your phone and cost nothing. The count resets every day at 1:30 PM IST.

Keep it safe

Your key stays only on your phone. Mimo never puts it in backups or exports.

Don't share it or post it online. If it ever leaks, delete it in Credentials and make a new one. It takes 30 seconds.

If something's off

"API key not valid"Part of the key is missing or has a space. Copy it again with Show key, paste, and tap Show to check.
"API not enabled"Step 2 was skipped, or another project is selected. Enable it, wait 2–3 minutes, press Test again.
"That's an OAuth client ID"You copied the wrong row. Use the row under API keys, not "OAuth 2.0 Client IDs".
"Quota exceeded"You played 99+ new songs today. Songs you've played before still work; new ones come back after 1:30 PM IST.
Still 30-second previewsThe key was tested but not saved. Press Save settings, then play the song again.
That's it
Now go press play
